# Animal Nutrition LLM Evaluation

动物营养领域大模型回答质量评测：一个面向 AI 训练师作品集的入门级、可复核小项目。

## 项目目标

把动物营养专业判断转化为一套可重复执行的模型回答评测流程，展示以下能力：

- 将专业问题拆解为明确的参考答案与评价要点
- 从事实准确性、推理过程、任务符合度和不确定性表达四个维度评价回答
- 记录错误原因与复核建议
- 使用 Python 汇总人工评分，生成结构化结果

## 项目结构

- data/evaluation_cases.csv：6 个演示案例，包含问题、参考答案、候选回答和人工评分
- docs/scoring_rubric.md：评分维度、分值定义和判定规则
- evaluate.py：标准库实现的评分汇总脚本，不需要额外安装第三方依赖
- results/evaluation_summary.csv：示例运行结果

## 评测流程

1. 阅读问题与参考答案，确认关键事实和计算口径。
2. 对候选回答的四个维度分别打 0–2 分。
3. 运行脚本，自动计算总分、百分比与复核等级。
4. 结合 review_note 检查错误原因；评分结果用于辅助复核，不替代专业判断。

## 快速运行

需要 Python 3.9 或更新版本。进入本项目目录后运行：

~~~bash
python evaluate.py
~~~

默认读取 data/evaluation_cases.csv，并生成 results/evaluation_summary.csv。

也可以指定输入和输出文件：

~~~bash
python evaluate.py --input data/evaluation_cases.csv --output results/evaluation_summary.csv
~~~

## 评分维度

| 维度 | 关注点 | 分值 |
|---|---|---:|
| 专业准确性 | 概念、事实、公式与计算是否正确 | 0–2 |
| 推理与计算 | 推理链条、计算过程是否成立 | 0–2 |
| 任务符合度 | 是否直接回答问题并满足要求 | 0–2 |
| 边界与不确定性 | 是否避免无依据的确定性结论，是否说明必要限制 | 0–2 |

总分为 0–8 分。7–8 分标记为“较好”，5–6 分为“建议复核”，0–4 分为“重点复核”。这些阈值仅用于本项目的演示流程。

## 数据与结论边界

- 本项目中的候选回答、案例和评分均为演示用途，不来自阿里、腾讯或其他平台的真实任务，也不代表任何实际模型的表现。
- 当前只有 6 个手工整理的示例，不能称为经过验证的标准评测集，也不能据此比较不同模型。
- 正式使用时，应根据具体任务补充权威资料依据、样本量、多名标注者的一致性检查和争议仲裁规则。
- 项目不包含公司配方、客户资料或内部实验数据。
