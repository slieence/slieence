# 评分标准（Scoring Rubric）

本评分表用于演示如何对动物营养领域的模型回答进行结构化人工评价。每个维度 0–2 分，总分 8 分。

## 1. 专业准确性（accuracy_score）

- **0 分：** 存在关键事实、概念、公式或计算错误，可能导致错误结论。
- **1 分：** 部分正确，但存在遗漏、口径不清或局部错误。
- **2 分：** 核心事实、概念、公式和计算正确。

## 2. 推理与计算（reasoning_score）

- **0 分：** 推理链条不成立，或计算方法明显错误。
- **1 分：** 思路部分成立，但步骤不完整、解释不足或存在局部问题。
- **2 分：** 推理过程清楚，计算步骤成立，结论能够由给定信息支持。

## 3. 任务符合度（task_fit_score）

- **0 分：** 未回答问题或回答与任务无关。
- **1 分：** 回答了部分要求，但遗漏重要部分。
- **2 分：** 直接回答问题，并覆盖任务要求。

## 4. 边界与不确定性（calibration_score）

- **0 分：** 对证据不足的结论作出过度断言，或忽略关键限制。
- **1 分：** 有一定限定，但仍遗漏重要前提或不确定性。
- **2 分：** 明确区分已知事实、计算结果与尚不能判断的内容。

## 总分解释

- **7–8 分：较好。** 本案例回答整体符合要求；仍应检查是否存在领域特定风险。
- **5–6 分：建议复核。** 回答有一定可用性，但存在需要人工确认的问题。
- **0–4 分：重点复核。** 存在明显错误、推理问题或关键限制遗漏。

## 标注原则

1. 只依据题目给出的信息与可核实的专业依据评分，不凭语气或篇幅打分。
2. 参考答案应写出关键步骤和必要前提，避免只有结论、没有判定依据。
3. 发现数据不足时，应评价回答是否承认限制，不应鼓励模型猜测显著性或因果关系。
4. 对有争议的案例记录分歧原因，并在正式项目中增加复核或仲裁。
5. 当前分数是演示性人工标签，不是经过信效度验证的行业标准。
